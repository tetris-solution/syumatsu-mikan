# 週末みかん

和歌山・有田の週末みかん農家コミュニティのLP初稿。ビルド不要のHTML / CSS / JavaScriptです。

## 起動

```sh
cd /workspace/syumatsu-mikan
npm run dev
```

Python 3のHTTPサーバーをポート3000で起動します。依存パッケージのインストールは不要です。

## 公開前の確認

- 開催日、農園所在地、集合場所、参加費、謝礼、保険、持ち物、参加条件、連絡・申込先を確定する。
- 周辺施設の最新情報と移動時間を確認する。
- 現在は受付機能・送信機能なし。参加案内は準備中として表示。
- グランピングは将来構想として掲載。
- メイン画像は生成した風景イメージ。実際の農園・収穫・運搬の写真へ差し替え可能。
- 提供された添付写真は実行環境でファイルとして取得できていないため未配置。

`index.html`で文言、`style.css`でデザイン、`assets/`で画像を管理します。
